# Shree Satyal Portfolio

A responsive personal portfolio built with HTML, CSS and JavaScript.

## Files
- index.html
- style.css
- script.js

## Deploy on GitHub Pages
1. Create a new GitHub repository.
2. Upload these three files to the repository root.
3. Go to Settings -> Pages.
4. Select the main branch and root folder.
5. Save and open the generated GitHub Pages URL.

The project cards already link to Shree's existing live projects.
